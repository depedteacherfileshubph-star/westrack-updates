# WESTrack app updates

Official Android releases for **WESTrack: Smart QR Attendance & SMS Notification System**.

Download the main APK from [Releases](https://github.com/depedteacherfileshubph-star/westrack-updates/releases).

To enable in-app updates, open WESTrack > Settings > App updates and save this repository URL:

    https://github.com/depedteacherfileshubph-star/westrack-updates

The app checks for newer versions and lets you download and confirm installation through Android. Updating preserves local records and activation. Automatic update checks need internet; everyday app use and activation remain offline.

Version 1.1.0 provides a one-calendar-month Trial from first use and supports dated activation or lifetime Pro. Administrator activation tools are distributed separately and are not part of this public repository.

This repository is for public downloads only. No learner records, activation generators, app source, credentials, or signing keys are stored here.
